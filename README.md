SOLMAR HEAT is an original open-world crime game set in the fictional coastal city of Solmar: explore on foot or by car, steal any vehicle, outrun Solmar PD under a five-star wanted level, fight rivals, and run eight story missions from fixer Vic Marlowe to the Solmar Heist — with a HUD, minimap, save game and synthesised sound, playable offline in a desktop browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
